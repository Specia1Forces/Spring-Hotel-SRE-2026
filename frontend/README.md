# Spring Hotel Frontend

Минимальный frontend на Vue 3 + Vite для REST API проекта Spring Hotel. Он повторяет только исходный набор функций из корневого README, без Pinia, UI-фреймворков и лишних экранов.

Подробное объяснение всех файлов, компонентов и функций находится в [FRONTEND_CODE_GUIDE.md](FRONTEND_CODE_GUIDE.md).

## Что реализовано

- вход и выход через сессию Spring Security;
- главное меню с учётом роли пользователя;
- дополнительные услуги: список, создание, изменение и удаление;
- клиенты и договоры: просмотр и создание;
- бронирования и счета: просмотр и создание;
- горничные и технический персонал: просмотр и создание;
- простая страница журналов-заглушка.

## Запуск

Сначала запустите backend на `http://localhost:8080` и PostgreSQL, как описано в корневом [README](../README.md).

Затем выполните:

```powershell
cd frontend
npm install
npm run dev
```

Frontend откроется на `http://localhost:5173`.

Маршруты используют hash-формат (`/#/clients`, `/#/bookings`), поэтому при простом размещении production-сборки дополнительная настройка SPA fallback не нужна.

Проверенный тестовый пользователь:

| Логин | Пароль | Роль |
|---|---|---|
| `manager` | `1234` | `MANAGER` |

Также backend содержит пользователей `admin` и `maids`; их пароли хранятся только как BCrypt-хеши в конфигурации безопасности.

## Настройка API

По умолчанию запросы отправляются на `http://localhost:8080/api/v1`. Для другого адреса создайте файл `.env.local`:

```env
VITE_API_URL=http://localhost:8080/api/v1
```

API-клиент автоматически отправляет session cookie и CSRF-токен. Хранить пароль или токен в `localStorage` не требуется.
При завершении сессии frontend очищает локальное состояние и возвращает пользователя на страницу входа.

## Команды

```powershell
npm run dev      # локальная разработка
npm run build    # production-сборка в dist
npm run preview  # просмотр production-сборки
```
